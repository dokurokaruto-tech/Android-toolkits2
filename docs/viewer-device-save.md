# 全画面から端末へ保存

生成画像の全画面表示に、緑枠＋「✓ 保存済み」と下部のダウンロードボタンを追加。
設定の「全画像に入れる」保存先へ原画像を保存し、全画像へ登録する。
保存先未設定・権限切れ・通信失敗時は案内を表示する。

- 保存済み判定はサムネイルキャッシュではなく、保存先の原画像を確認。
- 端末フォルダから開いた画像は、読み取り可能な実ファイルを確認して表示。
- 保存済み・保存中・確認中は保存ボタンを無効化。
- 保存開始時のURIを固定。ページ移動・一覧への新着追加で保存対象を変えない。
- 画面を閉じても、アプリプロセスが生きている間は保存を継続。
- 一覧の保存と全画面の保存は共通処理で直列化。保存中のファイルを保存済み表示しない。
- 完了時と画面復帰時に表示を更新。生成条件は保存後の再生成用に保持。
- 枚数カウンターを操作列の上へ移し、小画面でも下部ボタンを収める。

検証: Kotlinの実ポリシーによる独立チェック10項目、構文・XML検査に成功。
JVMテスト6件を追加。Gradle配布先へのTLS接続失敗により、APKビルド・実機検証は未完了。
実機では未保存→保存→一覧反映、保存中のページ移動・戻る、再起動後、権限切れ、
保存先未設定、同じシードでの再生成を確認する。
