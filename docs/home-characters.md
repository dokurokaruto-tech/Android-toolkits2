# ホームのキャラクター

カルーセル上の「キャラ変更」から後藤ひとり／喜多郁代／伊地知虹夏／山田リョウを選択する。
初期値は既存の後藤ひとり。選択は再起動・画面再生成後も保持する。

## 描画

既存の `BocchiLive2dStageView` と `BocchiPhysicsEngine` を共用する。
**Live2D Cubism SDK／moc3モデルではない。** Canvas の画像メッシュ変形による
独自2Dアニメーション。SDK、ネット接続、追加モデルのダウンロードは不要。

- 呼吸、首・髪・スカートの揺れ、自動瞬き、演奏動作。スクロールで視線・体・楽器が反応。
- 表情は8差分（瞬き・笑顔・演奏集中・歌い開口・驚き・待機の仕草など）。
  スクロールの演奏中は歌い開口と集中顔が1拍ごとに交代する。
- 頭タップ: ひとりはパニック、他3人はウィンク反応（グリッチなし）。
- キャラ別の個性付け:
  - 喜多: キューブ髪飾り・アホ毛・グリッチ無効、バウンス増幅。赤系アクセント＋金色の輝き。
  - 虹夏: 三角アホ毛、サイドポニーの波、両スティック腕のドラム動作、ドラム打撃エフェクト。
  - リョウ: 全体の揺れを減衰しクールな佇まい。目線の輝きは歌唱時のみ控えめに。
- 切替時は物理状態を初期化し、選択中の機能セクションは維持。
- 全素材の読み込み成功後に交換。失敗時は現在のキャラクターを維持。

## 素材・参考

公式紹介（2026-10-01参照）:
https://www.aniplex.co.jp/lineup/bocchi/news/detail/?id=60203

喜多の楽器はペルハムブルーのレスポール・ジュニア・ダブルカッタウェイ、
リョウの楽器は白のプレシジョンベースを資料で確認し反映した。
今回の画像はAI生成の非公式ファンアート。公式画像や第三者のLive2Dモデルを
アプリ素材として転載していない。作品・キャラクターの権利は各権利者に帰属する。
生成した素材の同梱は、権利者からの配布許諾を意味しない。

`assets/live2d/<キャラ>/` は既存リグに合わせた592×750のボディと、
全キャラ共通の顔矩形 (160,90)-(316,216) の156×126顔差分8種。
表情は同じボディから生成して位置を固定し、顔差分の端はボディと同一ピクセル。
ボディ元画像は緑背景を除去し、足元をフェード処理。素材の再生成:

```sh
python tools/build_character_bodies.py <元画像ディレクトリ> # Pillow・NumPyが必要
python tools/build_character_faces.py
python -m unittest discover -s tools -p 'test_character_assets.py'
```

## 検証

- 素材テスト（4キャラ分）: 透過、寸法、緑背景除去、顔差分の境界・差分存在を確認済み。
- Kotlin 2.2.10による実ソースの独立モーション検証: 4キャラ各3,600フレーム成功。
  保存値復元、既存キャラ互換、頭タップ、瞬き、髪・ポニー揺れ、ドラム変換、
  頂点の有限値、顔位置を確認。Android生成リソースIDのみスタブ。
- ポリシー系JUnitテスト17件（スタブ実行）と `BocchiLive2dStageView` の
  android.jar（API 36）対象コンパイルを確認済み。

```sh
JAVA_HOME=/path/to/java KOTLINC=/path/to/kotlinc tools/check_character_motion.sh
./gradlew :app:testDebugUnitTest :app:assembleDebug
```
