# ホームのキャラクター

カルーセル上の「キャラ変更」から後藤ひとり／喜多郁代／伊地知虹夏／山田リョウを選択する。
初期値は既存の後藤ひとり。選択は再起動・画面再生成後も保持する。

## 描画

既存の `BocchiLive2dStageView` と `BocchiPhysicsEngine` を共用する。
**Live2D Cubism SDK／moc3モデルではない。** Canvas の画像メッシュ変形による
独自2Dアニメーション。SDK、ネット接続、追加モデルのダウンロードは不要。

顔・楽器・髪の計測点は `CharacterRig`（キャラ別）に分離した。592×750キャンバスは共通。

- 呼吸、首・髪・裾の揺れ、自動瞬き、演奏動作。虹夏はスティックが150BPMの8分で左右交互に叩き、打面リングとシンバル閃光が出る。
- 待機中はウィンク→うっとり→笑顔→驚きの自発エモートを巡回。機能セクションでも表情が変わる。
- 頭タップ: ひとりはパニック、他3人はエモート。楽器タップはグルーヴ表情。
- 喜多はサイド結び、虹夏はドリト型アホ毛・水玉リボン・ポニーテール、リョウはボブ向けに揺れを調整。グリッチはひとりのみ。
- ステージ色: ひとり=ピンク、喜多=赤、虹夏=黄、リョウ=青。
- 切替時は物理状態を初期化し、選択中の機能セクションは維持。
- 全素材の読み込み成功後に交換。失敗時は現在のキャラクターを維持。

## デザインの根拠

原作者の私服設定（喜多=可愛い系トレンドブランド、虹夏=サブカル系、リョウ=古着系）と
公式の私服・ストリートファッション描き下ろしを参照した（2026-10-20参照）。
- 喜多: ピンク×白スタジャン＋星柄フリルトップス＋水色リボンチョーカー＋デニムミニ、花柄ストラップの青ギター。
- 虹夏: 緑スタジャン＋白T＋マスタードスカート。ワインレッドのドラムセット、左に黒スネア。
- リョウ: 紺シャツジャケット＋黒インナー＋リングペンダント＋グレーワイドパンツ、ヘッドホンを首下げ、白プレベ。

出典例:
- 公式キャラ紹介 https://bocchi.rocks/omnibus/character/ikuyo.html
- 私服設定インタビュー https://mannavi.net/19238/
- 喜多私服Ver.（第9話の星柄ワンピース）https://hobby.dengeki.com/news/2576261/

## 素材

今回の画像は、既存ぼっち素材を作風リファレンスとしてAI生成した非公式ファンアート。
公式画像や第三者のLive2Dモデルをアプリ素材として転載していない。
作品・キャラクターの権利は各権利者に帰属する。
生成した素材の同梱は、権利者からの配布許諾を意味しない。

`assets/live2d/{kita,nijika,ryo}/` は透過WebP。クロマキー抜き後に592×750へ
位置合わせし、足元を既存素材と同じ傾斜でフェード処理した。
顔差分は8種（半瞬き・瞬き・笑顔・グルーヴ・チア・ウィンク・驚き・うっとり）。
キャラ別の顔枠・目・口座標から同じボディ上で描画し、枠の端ピクセルはボディと同一。
ボディ修正後は以下で差分を再生成する。

```sh
python tools/build_live2d_faces.py # Pillowが必要
python -m unittest discover -s tools -p 'test_live2d_assets.py'
```

## 検証

- 素材テスト3件: 透過、寸法、キー色残留、顔差分の境界・差分存在を確認済み。
- Pythonへ変形関数を移植し、誇張ポーズで3人のメッシュ変形と顔パッチ追従を目視確認済み（検証用スクリプトは未同梱）。
- Kotlin独立モーション検証とJUnitテストは下記。選択復元、互換性、頭タップ、ドラム交互ヒット、自発エモート、瞬き、頂点の有限値、顔位置を全キャラで確認する想定。

```sh
JAVA_HOME=/path/to/java KOTLINC=/path/to/kotlinc tools/check_character_motion.sh
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

この環境ではJDK／Android SDKを取得できなかったため、Kotlinコンパイル・Gradleテスト・
APKビルド・実機描画は未検証。静的レビューとPython移植で代替確認した。

実機で確認する項目:
1. 4キャラの切替、再起動・回転後の選択保持。
2. 待機時の瞬き・呼吸・エモート巡回、頭／楽器のタップ、カルーセルスクロール。
3. 虹夏のスティック動作と打面リング、リョウのベース弦エフェクト。
4. 機能画面から戻った際のアニメーション再開、バックグラウンド時の停止。
5. 小画面・横画面・大きな文字設定でのボタンとカルーセルの操作。
