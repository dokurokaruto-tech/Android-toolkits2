# 日記・「私の図書館」のファイルバックアップ

バックアップ先の登録に Google Cloud Console や OAuth クライアントは必要ありません。Android のファイル選択画面（SAF）でバックアップ ZIP を一度選び、アプリがその URI の永続的な読み書き権限を取得して更新します。

## 使い方

1. 「私の図書館」を開き、右上のバックアップアイコンをタップします。
2. 「保存先ファイルを選択」から、次のどちらかを選びます。
   - **新しいバックアップを作成**: `MyLibraryBackup.zip` を新規作成します。
   - **既存のバックアップを選択**: アプリが作成したバックアップ ZIP を選びます。既存のローカル記録は消さず、項目ごとの更新日時でマージしてからファイルを更新します。
3. ファイル選択画面で Google Drive が表示される端末では、保存場所として Google Drive を選べます。Drive が表示されない場合は、その端末で利用できる別のドキュメントプロバイダーを選んでください。

日記・写真・エッセイ・やりたい事リストを ZIP にまとめます。保存先を設定した後は、日記またはノートを保存するとバックグラウンドで ZIP を更新します。「今すぐバックアップ」から手動更新もできます。更新が失敗した場合は状態欄に表示され、次回アプリを開いた際に未完了の更新を再試行します。

## 動作上の注意

- 保存先プロバイダーが永続的な読み書き権限とファイル更新に対応している必要があります。対応していない場合は、別の保存先を選んでください。
- 既存ファイルを選ぶときは、このアプリが作成したバックアップ ZIP を指定してください。無関係な ZIP は取り込まず、ローカルデータも削除しません。
- これは選択した1ファイルへのバックアップです。複数端末間のリアルタイム同期ではありません。別端末で同じファイルを使う場合は、その端末でも一度ファイルを選んで取り込み、その後の更新結果を確認してください。
- 「保存先の設定を解除」はアクセス権と URI の登録だけを解除します。バックアップファイル自体は削除しません。
